# Secretary: 游戏非官方简体中文汉化

> **Secretary Unofficial Simplified Chinese Localization**

这是一个为 **Secretary** 制作的非官方简体中文汉化项目。

本项目旨在帮助中文玩家更方便地体验游戏内容。汉化内容由社区/个人爱好者制作，与游戏原作者及官方团队没有任何隶属关系。

> ⚠️ **本项目仅提供汉化相关内容，不提供、不包含游戏本体。请通过官方渠道获取游戏。**

---

## 📖 关于游戏

**Secretary** 是一款成人向的冒险与生活模拟游戏。玩家将扮演一名原本从事白领工作的角色，在生活发生变化后，开始面对一段与新上司有关的特殊经历。

游戏包含成人主题、性内容、性别表达、BDSM 等内容，仅建议符合当地法律规定年龄的成年人游玩。

---

## ✨ 项目目标

* 将游戏文本翻译为简体中文
* 尽可能保留原作的剧情、角色与表达风格
* 尽量保持游戏原有的变量、代码和游戏机制不受影响
* 持续跟进游戏版本更新
* 为中文玩家提供一个开放、可改进的本地化项目

欢迎通过 Issue 或 Pull Request 帮助改进翻译、报告问题或补充遗漏内容。

## 🚀 使用方法

> 使用前请务必备份你的游戏文件和存档。

1. 通过官方渠道获取 **Secretary: The Game** 游戏本体。
2. 前往本项目的 [Releases](../../releases) 页面下载对应版本的汉化文件。
3. 按照 Release 页面提供的说明安装汉化。
4. 启动游戏并开始游玩。

具体安装方式可能会随着游戏版本和汉化方案的变化而调整，请以最新 Release 的说明为准。

## 📝 翻译原则

本项目尽可能遵循以下原则：

1. **尊重原意**：优先准确表达原文内容。
2. **保持角色风格**：不同角色的说话方式尽可能保持一致。
3. **中文自然**：避免生硬的机器翻译式表达。
4. **术语统一**：相同的游戏机制、角色和物品使用统一译名。
5. **保留技术内容**：变量名、代码、标签和游戏机制相关内容原则上不进行可能导致程序异常的修改。
